# Game Center achievement artwork

These five original Mahjong Brain assets are the upload source for the U.S.
English Game Center achievement localizations documented in
`release/GAME_CENTER_SETUP.md`.

## QA contract

- 1024 x 1024 pixels
- RGB PNG
- no alpha channel
- no text, numerals, competitor marks, or copied ornamental layouts
- important artwork remains inside the center safe area for Apple’s circular
  presentation mask
- shared visual language: ivory 3D tile, emerald glass, gold light, and a
  restrained coral accent

Do not replace an image in App Store Connect without replacing the corresponding
file here and re-running the dimension, color-space, alpha, and visual-drift
checks.
